# mskdevhub-website

Source for the **MSK Real Labs** portfolio website by Muhammad Shaheer Kifayat
(brand: *mskreallabs*). Originally built and deployed with Cloudflare Wrangler,
now served through **Cloudflare Pages** with Git integration.

- **Repository:** https://github.com/mskdevhub/mskdevhub-website
- **Production URL:** https://mskdevhub-website.pages.dev
  (previous project: https://mskreallabs.pages.dev)

> The site's design, content, routes, assets and behaviour are preserved from the
> original project. Only the deployment/organisation details changed.

## Stack

| Layer | Technology |
|---|---|
| Frontend | Static HTML / CSS / vanilla JS (`public/`) |
| API | Cloudflare Pages Functions (advanced mode), bundled from `src/index.js` with **Hono** |
| Runtime entry | `public/_worker.js` (generated by esbuild — **not** committed) |
| Database | Cloudflare **D1** binding `DB` (database `databse`) |

### API routes (`src/index.js`)

- `POST /api/contact` — stores contact form messages
- `POST /api/auth/login` — password login (PBKDF2 + JWT cookie)
- `POST /api/auth/signup` — account creation
- `*` — falls through to static assets (`env.ASSETS`)

## Repository structure

```
.
├─ public/                 # Static site root = build output directory
│  ├─ index.html           # Home
│  ├─ contact/ projects/ resume/ services/ skills/   # Sub-pages
│  ├─ _posts/              # Case-study pages
│  ├─ includes/            # HTML fragments loaded at runtime
│  ├─ assets/              # css, js, images, pdfs
│  ├─ _headers robots.txt sitemap.xml 404.html
│  └─ _worker.js           # GENERATED at build time (gitignored)
├─ src/index.js            # Hono API worker source
├─ database/               # D1 schema / seed / local bootstrap SQL
├─ wrangler.toml           # Pages config (output dir + D1 binding)
├─ package.json            # Build + deploy scripts
└─ package-lock.json
```

## Local development

```powershell
npm install
npm run build            # bundles src/index.js -> public/_worker.js
npm run db:init:local    # creates local D1 tables
npm run dev              # wrangler pages dev public
```

## Deployment

Deployment uses **Cloudflare Pages Git integration**: pushing to `main`
triggers a build and deploy automatically.

Recommended Cloudflare Pages build settings:

| Setting | Value |
|---|---|
| Production branch | `main` |
| Root directory | `/` (repository root) |
| Build command | `npm run build` |
| Build output directory | `public` |

Required Cloudflare configuration (both **Production** and **Preview**):

- **D1 binding** — name `DB` → database `databse`
  (id `d6a8d579-962e-4288-bf38-6494e5dc312f`, also declared in `wrangler.toml`)
- **Environment variable** — `JWT_SECRET` (encrypted). The login API returns a
  500 if this is missing.

`wrangler.toml` already declares the output directory and D1 binding, so Pages
reads them during Git builds.

### Manual (Wrangler) deploy — optional

```powershell
npm run deploy           # wrangler pages deploy public --project-name mskdevhub-website
```

Only use this if you intentionally switch to Direct Upload; with Git integration
a `git push` is enough.
