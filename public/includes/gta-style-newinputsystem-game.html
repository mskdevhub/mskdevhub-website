Overview

GTA Style New Input System Game is a project built using Unity and C# scripting. The project focuses on utilizing Unity's New Input System to create responsive character controls similar to classic GTA-style games.

"Implementing modern input systems provides a much more flexible and scalable approach to character controls."

Key Features

New Input System

Utilizes Unity's New Input System for flexible control mapping.

Character Movement

Smooth 3D character movement and camera controls.

Action Mechanics

Core action mechanics for an open-world feel.

Cross-Platform Ready

Ready for Windows, Android, and WebGL browsers.

Installation & Usage

Running the game locally requires Unity Hub and Unity Editor.

  • Clone the repository from GitHub: git clone https://github.com/mskreallabs/GTA-Style-NewInputSystem-Game.git.
  • Open Unity Hub, click Add, and select the cloned project directory.
  • Ensure the correct Unity version is selected and launch the project.
  • Press the Play button in the editor toolbar to run and test the game.
